Use the wiki skill to ingest a source. Pass all arguments through.

Common usage:
- `/wiki:ingest --conversation` — Capture learnings from this session
- `/wiki:ingest --conversation "topic name"` — Capture with explicit topic
- `/wiki:ingest --research "topic"` — Research a topic from the web
- `/wiki:ingest <url>` — Ingest a webpage
- `/wiki:ingest <file>` — Ingest a local file
- `/wiki:ingest --no-compile <source>` — Ingest without auto-compiling
